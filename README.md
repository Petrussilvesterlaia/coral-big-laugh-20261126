Entry for the make.fun bounty [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) — a single funny line, written by a small Python program to `/output/entry.txt`.

The line:

> My therapist told me to embrace my mistakes, so I hugged my ex — now we share the same therapist.

## Run it

```bash
python3 main.py
```

This writes the line to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The program validates the line first — one line only, 1–200 characters, no leading or trailing whitespace, no control characters — and reads the file back to confirm the bytes on disk match exactly.
